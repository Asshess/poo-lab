# Teatro

Sistema de venta de entradas con entradas normal, reducida y de abonado. Practica herencia, polimorfismo y pruebas con JUnit 5.

## Ejecutar

```bash
cd teatro
mvn test
mvn -q exec:java -Dexec.mainClass=teatro.Main
```

## Contenido

- `teatro/src/main/java/teatro/` — clases del dominio.
- `teatro/src/test/java/teatro/EntradaTest.java` — pruebas de precios.
- `teatro.puml`, `help.puml` — diagramas.
- `IMG_7775.jpg` — imagen de apoyo.
