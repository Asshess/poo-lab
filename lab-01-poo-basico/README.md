# Lab 01 — POO básico: VirtualPet

Mascota virtual en Java con interfaz Swing. Practica clases, encapsulamiento, herencia, polimorfismo, interfaces y validación de límites.

## Ejecutar

```bash
cd VirtualPet
ant          # compila y abre la interfaz
ant compile  # solo compila
```

Requiere JDK y un entorno gráfico. La interfaz está en `main.java.InterfazMascota`; `Main` es una demo de consola.

## Contenido

- `VirtualPet/src/main/java/` — código (`Mascota`, `Pokemon`, `InterfazMascota`, `Main`).
- `VirtualPet/build.xml` — build de Ant.
- `VirtualPet/Informe.pdf` — informe entregado.
- `informe.md` — explicación del diseño y evidencias.
- `VirtualPet.puml` — diagrama de clases.
- `01_Lab_POO_Basico.pdf` — enunciado.
- `log.png`, `limite.png` — evidencias de ejecución.
