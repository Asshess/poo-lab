# Lab 03 — POO avanzado: farmacia

Simulación de un brazo robótico que transfiere medicamentos entre una tolva (LIFO) y una cinta de salida (FIFO). Practica genéricos, colecciones, excepciones propias y jerarquía de clases.

## Ejecutar

```bash
ant
java -jar dist/JavaApplication17.jar
```

`ant` compila y genera el jar en `dist/` (se recrea; no se versiona). El proyecto conserva la estructura de NetBeans (`nbproject/`).

## Contenido

- `src/farmacia/` — modelo, estructuras y excepciones.
- `03_Lab_POO_Avanzado.pdf` — enunciado.
- `nbproject/` — configuración del proyecto NetBeans.
