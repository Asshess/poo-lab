# Ejercicio

Se quiere establecer una relacion de orden entre numeros y lineas respectivamente.

Se conoce que una linea se forma a partir de la union de dos puntos con coordenadas X,Y

Se requiere determinar si un numero es mayor, menor, o igual a otro. En el caso de las lineas se debe determinar la longitud de estas para poder relacionarlas y saber si una linea es mayor, menor o igual a otra.

Se pide crear una clase Numero y una clase linea e implementar los metodos necesarios que permitan cumplir con lo solicidado.

## Crear un arreglo de numeros y lineas e indicar para cada posicion del arreglo lo siguiente:

- Mostrar mensaje que indique si se estan comparando numeros o lineas

- Si la comparacion es entre numeros indicar si el primer numero es mayor, menor o igual al segundo.

- Si la comparacion es entre lineas indicar las coordenadas de cada una y si la primera linea tiene una longitud mayor, menor o igual a la segunda linea
